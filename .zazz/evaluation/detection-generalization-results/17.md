### What was given up, and what replaced it

| Change | Why | Cost |
|---|---|---|

| Methods, PDO, SQLite3, double quotes, `.=`, code between escape and query | Not provable from the pattern | `s-esc-append`, `s-esc-double` state none. They were `vulnerable` with the fact too |

## Soundness

- 89 forms of the review: each makes a record, none states a fact. Before: 89 of 89 did.
- 186 variants of the findings written for this change, not the posted forms. Before the last fix four spellings of `SET NAMES`
  stated a fact. Now one form has a fact: the first of two queries in one form, where it is true.
- Tests: 26 forms with a fact, 210 traps that each make a record, 43 programs of more than one file, 105 SQL texts and the 89 review forms.
  64 more variants of the integer and digit facts were run by hand; the 8 that state a fact are true.
- Mutants: every logical operand, comparison, condition, negation, list entry, case and statement of `sql_facts.go`,
  `sql_operand_text.go` and `sql_digit_guard.go`, changed one at a time: 581, of which 5 do not build and **1 of 576 survives** (the
  program check is computed again instead of kept, which changes no result). 37 changes of the expressions and of the request code: all are killed. At `768171d` 32 of 35 survived.
- PHP 8.6 runs showed that an error handler, a destructor and `__toString` can change a variable between two plain assignments.
  The program conditions withhold the fact for each.
- **Re-review at `64b80b2` (R30 to R34).** A reference that `&$name` does not show (`$GLOBALS['n'] = &$GLOBALS['e']`, a by-reference
  function, `extract($a, 256)`) let an escape rewrite a bare integer: now only integers may follow an integer operand's last write.
  A handler named at run time, in a `.inc` file or in `vendor/`, is now found by reading every file under the root. `"$v?->x"` and a
  repeated fact line are fixed. **No judged request changed:** every paid answer above still applies. `s-mixed` states no fact. Mutants of `sql_facts.go` after these fixes: 341 build, 334 killed; the 7 that survive are the cache, the walk's
  early stop, and error branches of the directory walk that no portable test can reach.

**Not excluded, and stated in [query judgment](../../architecture/query-judgment.md#facts-about-constructed-php-sql-operands):** code
outside the scanned files, a character set or SQL mode that no scanned PHP file sets, database triggers, and an engine that is not MySQL
behind `mysqli`. No MySQL server was available, so the server behavior rests on its documentation.
