Zazzles Code Scan sample reports

Code Scan traces untrusted input to sensitive operations and records the controls on each path. A decision model then judges that evidence. These are saved reports on intentionally vulnerable applications. Expand an entry to see the source evidence, the outcome and the remediation.

Each report is standalone, and viewing one makes no model call. Outcomes are static source judgments, not runtime exploit confirmation. Project on GitHub · Detection capabilities · How to read a report

Semgrep CE 1.183.0 ran twice: with 23 registry packs chosen to fit these applications (1,379 rules), and with five focused packs (564 rules). Broad packs find more and report more safe code. Its cross-function and cross-file engine is a paid product and was not run. Bearer CLI ran bearer-rules; Bearer Pro was not run.

These are different kinds of tool. Semgrep CE and Bearer run free and offline. A judged Code Scan calls a paid model provider. Code Scan was developed against these applications and the answer keys favor the classes it analyzes, so this is not a general accuracy claim. Its found count includes three Juice Shop cases reported as practice findings. It misses one committed secret, a class it has no analyzer for.
