# Scan

[Zazzles modules](../README.md#modules)

Scan analyzes JavaScript, TypeScript, Python and PHP application source. Its reports contain
the operation, paths, controls and evidence gaps for each claim. Optional model assessment
helps evaluate supported claims.

- [Build and run Scan](../README.md#quick-start)
- [Detection capabilities](../docs/detection-capabilities.md)
- [Interpreting results](../docs/interpreting-results.md)
- [Sample reports](../docs/samples/README.md)

The Go command is in [cmd/scan](../cmd/scan/). The analyzer, pipeline and reporting packages
are in [internal](../internal/). [Contributor guide](../docs/contributing.md)
