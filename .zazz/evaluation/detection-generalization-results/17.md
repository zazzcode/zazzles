## Soundness

- 89 forms of the review: each makes a record, none states a fact. Before: 89 of 89 did.
- 186 variants of the findings written for this change, not the posted forms. Before the last fix four spellings of `SET NAMES`
  stated a fact. Now one form has a fact: the first of two queries in one form, where it is true.
- Tests: 20 forms with a fact, 152 traps that each make a record, 43 programs of more than one file, 92 SQL texts and the 89 review forms.
- Mutants: every logical operand, comparison, condition, negation, list entry, case and statement of `sql_facts.go` and
  `sql_operand_text.go`, changed one at a time: 472, of which 4 do not build and **1 of 468 survives** (the program check is
  computed again instead of kept, which changes no result). 36 changes of the expressions and of the request code: none survives, and
  one more does not build. At `768171d` 32 of 35 survived.
- PHP 8.6 runs showed that an error handler, a destructor and `__toString` can change a variable between two plain assignments.
  The program conditions withhold the fact for each.

**Not excluded, and stated in [query judgment](../../architecture/query-judgment.md#facts-about-constructed-php-sql-operands):** code
outside the scanned files, a character set or SQL mode that no scanned PHP file sets, database triggers, and an engine that is not MySQL
behind `mysqli`. No MySQL server was available, so the server behavior rests on its documentation.
