Zazzles Code Scan sample reports

Code Scan traces untrusted input to sensitive operations and records the controls on each path. A decision model then judges that evidence. These are saved reports on intentionally vulnerable applications. Expand an entry to see the source evidence, the outcome and the remediation.

Each report is standalone, and viewing one makes no model call. Outcomes are static source judgments, not runtime exploit confirmation. Project on GitHub · Detection capabilities · How to read a report

An answer key is not a complete list of an application’s vulnerabilities. Juice Shop’s was extended to 75 rows from its own documented challenges and markers and from results of any scanner. The others were not extended and still favor the classes Code Scan analyzes. The two Code Scan columns differ in scanner revision as well as model; the gpt-6-luna VulnPy report predates the deserialization analyzer.

Semgrep CE 1.183.0 ran with 23 registry packs (1,379 rules). Its cross-function and cross-file engine is a paid product and was not run. Bearer CLI ran bearer-rules; Bearer Pro was not run.

These are different kinds of tool. Semgrep CE and Bearer run free and offline. A judged Code Scan calls a paid model provider. Code Scan was developed against these applications, so this is not a general accuracy claim. Its gpt-6-luna found count includes three Juice Shop cases reported as practice findings; the Gemini count includes one Juice Shop and one VulnerableSymfony case.
